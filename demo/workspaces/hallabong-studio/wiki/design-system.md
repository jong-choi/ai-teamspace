# 디자인 시스템 가이드

화면을 만들 때 지키는 규칙입니다. 시안과 코드가 같은 이름을 씁니다.

## 색

| 이름      | 쓰는 곳                                       |
| --------- | --------------------------------------------- |
| `primary` | 주문, 결제처럼 화면에서 가장 중요한 버튼 하나 |
| `surface` | 카드와 시트의 배경                            |
| `muted`   | 보조 설명, 비활성 상태                        |
| `danger`  | 삭제, 취소처럼 되돌릴 수 없는 동작            |

한 화면에 `primary` 버튼은 하나만 둡니다.

## 글자

- 본문은 `body`, 보조 설명은 `caption`을 씁니다.
- 굵기로 강조하고, 색으로 강조하지 않습니다.
- 숫자가 세로로 나란히 놓이는 곳은 고정폭 숫자를 씁니다.

## 간격

4의 배수만 씁니다. 카드 안쪽 여백은 16, 카드 사이는 12입니다.

## 컴포넌트를 새로 만들기 전에

1. 이미 있는 컴포넌트로 되는지 봅니다.
2. 안 되면 디자인 채널에 사례를 올립니다.
3. 두 화면 이상에서 쓰일 때만 시스템에 넣습니다.

## 접근성

- 누를 수 있는 것은 가로세로 44 이상입니다.
- 글자와 배경의 대비는 4.5:1 이상입니다.
- 아이콘만 있는 버튼에는 읽어 줄 이름을 붙입니다.
