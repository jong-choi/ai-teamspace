# 파이프라인 구조

## 흐름

1. **수집**: 서비스 DB의 변경 내역과 앱 이벤트를 받는다.
2. **원본 보관**: 받은 그대로 날짜별로 쌓는다. 고치지 않는다.
3. **정제**: 중복을 없애고 형식을 맞춘다.
4. **분석용 테이블**: 주문, 상품, 농가, 배송 단위로 묶는다.

## 실행 시각

- 매일 새벽에 전날 데이터를 처리합니다.
- 아침 업무 시작 전에 분석용 테이블이 준비돼야 합니다.

## 실패했을 때

- 작업은 세 번까지 다시 시도합니다.
- 한 시간 넘게 밀리면 담당자에게 알림이 갑니다.
- 원본이 남아 있으므로 어느 단계든 그날 것만 다시 돌릴 수 있습니다.

## 작업 사이의 순서

| 작업               | 먼저 끝나야 하는 것  |
| ------------------ | -------------------- |
| 주문 정제          | 주문 수집            |
| 상품 정제          | 상품 수집            |
| 주문 분석용 테이블 | 주문 정제, 상품 정제 |
| 추천 학습 데이터   | 주문 분석용 테이블   |
