# 결제와 정산 구조

주문 한 건이 결제되고 농가에 정산되기까지의 흐름입니다.

## 흐름

1. 고객이 결제를 요청한다.
2. 서버가 결제 대행사(PG)에 승인을 요청한다.
3. 승인되면 주문이 **결제 완료**가 되고 농가에 알림이 간다.
4. 농가가 발송하면 **배송 중**이 된다.
5. 배송이 끝나고 사흘 뒤 **구매 확정**이 된다.
6. 구매 확정된 주문이 정산 대상이 된다.

## 승인 요청 규칙

- PG 응답은 8초까지 기다립니다.
- 응답이 없으면 한 번만 다시 시도합니다.
- 두 번 모두 실패하면 고객에게 다른 결제 수단을 안내합니다.

## 정산

지금은 주 단위로 정산합니다. 일 단위로 바꾸는 작업이 진행 중입니다.

| 항목      | 주 단위             | 일 단위 (예정)     |
| --------- | ------------------- | ------------------ |
| 정산 주기 | 매주 한 번          | 매일 오전          |
| 환불 차감 | 같은 주 안에서 상계 | 다음 정산에서 차감 |
| 정산서    | 화면에서만 확인     | 파일로 내려받기    |

## 환불

- 정산 전 환불: 정산 대상에서 뺍니다.
- 정산 후 환불: 다음 정산 금액에서 차감하고, 정산서에 차감 내역을 한 줄로 보여 줍니다.
