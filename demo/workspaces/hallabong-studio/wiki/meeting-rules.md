# 회의 운영 원칙

회의는 비쌉니다. 여섯 명이 한 시간 모이면 여섯 시간을 쓰는 셈입니다.

## 잡기 전에

- 글로 해결되는 일이면 회의를 잡지 않습니다.
- 초대할 때 **안건**을 적습니다. 안건이 없는 회의는 거절해도 됩니다.
- 기본 길이는 30분입니다. 한 시간이 필요하면 이유를 적습니다.

## 하는 동안

- 정시에 시작하고 정시에 끝냅니다.
- 진행자와 기록자를 처음에 정합니다.
- 결정이 필요한 안건부터 다룹니다.

## 끝난 뒤

- 기록자는 그날 안에 회의록을 올립니다.
- 회의록에는 **결정한 것**과 **누가 무엇을 언제까지 하는지**만 적습니다.
- 할 일은 티켓으로 만듭니다.

## 정기 회의

| 회의            | 요일        | 참석        |
| --------------- | ----------- | ----------- |
| 스프린트 플래닝 | 월요일 오전 | 개발, QA    |
| 전체 회의       | 금요일 오후 | 전원        |
| 일대일 면담     | 격주        | 리드와 팀원 |
