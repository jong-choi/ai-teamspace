# 추천 모델 2.0 설계

## 지금 모델의 한계

지금 모델은 "전에 산 것과 비슷한 것"을 추천합니다. 재구매에는 잘 맞지만 고객이 처음 보는 농가나 품목은 거의 추천하지 못합니다.

## 목표

고객이 **처음 사는 상품**을 더 잘 맞힌다.

## 구조

두 단계로 나눕니다.

1. **후보 생성**: 전체 상품에서 200개를 빠르게 고른다.
2. **순위 매기기**: 200개를 다시 정렬해 10개를 보여 준다.

### 후보 생성

- 고객과 상품을 같은 공간의 벡터로 만든다.
- 고객 벡터와 가까운 상품을 고른다.
- 새로 올라온 상품도 상품 설명과 품목으로 벡터를 만들 수 있어 후보에 들어온다.

### 순위 매기기

| 신호   | 설명                                       |
| ------ | ------------------------------------------ |
| 제철   | 지금 수확 중이거나 곧 수확하는 상품에 가점 |
| 지역   | 고객 주소로 배송되지 않는 상품은 제외      |
| 취향   | 품목, 가격대, 포장 단위 선호               |
| 새로움 | 고객이 산 적 없는 농가에 가점              |

## 걸러 내는 것

- 품절 상품
- 배송 불가 지역 상품
- 고객이 최근에 환불한 상품

## 서비스 적용

앱 홈 화면의 추천 영역에 자리를 먼저 만들고, A/B 테스트 결과를 본 뒤에 전체에 켭니다.
