# 온보딩 가이드

첫 주에 할 일을 순서대로 적었습니다. 막히는 곳이 있으면 담당 멘토에게 바로 물어보세요.

## 첫날

- [ ] 계정 받기: 메일, 메신저, 코드 저장소, 디자인 도구
- [ ] 귤밭 앱을 설치하고 실제로 주문해 보기 (비용은 회사가 냅니다)
- [ ] 팀 핸드북 읽기
- [ ] 멘토와 점심

## 첫 주

- [ ] 개발 환경 설정 (개발 직군)
- [ ] 디자인 시스템 가이드 읽기 (디자인·프론트엔드 직군)
- [ ] 고객 문의 응대 하루 참관
- [ ] 주간 전체 회의에서 자기소개

## 첫 달

- [ ] 작은 티켓 하나를 처음부터 출시까지 맡아 보기
- [ ] 농가 한 곳 방문 (분기마다 일정이 잡힙니다)

## 자주 묻는 것

| 질문                              | 답                                                     |
| --------------------------------- | ------------------------------------------------------ |
| 장비는 언제 받나요                | 입사 전 주에 택배로 보냅니다                           |
| 출근 시간이 정해져 있나요         | 오전 10시부터 오후 4시까지는 모두 연락이 닿아야 합니다 |
| 누구에게 물어봐야 할지 모르겠어요 | 공지 채널에 올리면 아는 사람이 답합니다                |
