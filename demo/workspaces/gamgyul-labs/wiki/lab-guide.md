# 랩 운영 안내

감귤랩스는 농산물 직거래 서비스에 쓰이는 추천과 데이터 기술을 연구합니다. 연구 결과는 파트너 서비스인 귤밭 앱에 먼저 적용합니다.

## 팀

| 팀     | 하는 일                    |
| ------ | -------------------------- |
| 추천   | 상품 추천 모델 연구와 평가 |
| 데이터 | 데이터 적재, 품질, 비용    |
| 분석   | 실험 설계와 결과 해석      |

## 일하는 방식

- 실험은 시작하기 전에 **가설과 중단 기준**을 적습니다.
- 결과가 나쁜 실험도 기록합니다. 같은 실험을 두 번 하지 않기 위해서입니다.
- 매주 수요일 연구 세미나에서 한 사람이 발표합니다.

## 파트너와 일할 때

- 파트너 서비스의 고객 데이터는 랩 밖으로 가져가지 않습니다.
- 서비스에 적용하는 일정은 파트너의 릴리스 일정을 따릅니다.
