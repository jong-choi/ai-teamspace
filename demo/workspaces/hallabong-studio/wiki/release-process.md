# 배포 절차

## 서버

1. 리뷰를 통과한 변경을 기본 브랜치에 합친다.
2. 자동 검사(형식, 타입, 테스트)가 통과하면 검증 환경에 자동으로 올라간다.
3. 검증 환경에서 QA가 확인한다.
4. 운영 배포는 담당자가 버튼을 눌러 시작한다.

운영 배포는 평일 오전 11시부터 오후 4시 사이에만 합니다. 금요일 오후에는 하지 않습니다.

## 앱

- 격주로 스토어에 올립니다.
- 올리기 이틀 전에 코드를 얼리고, 그 뒤로는 버그 수정만 넣습니다.
- 출시 여부는 Go/No-Go 회의에서 정합니다.

## 되돌리기

- 서버는 직전 버전으로 바로 되돌릴 수 있습니다. 5분 안에 판단합니다.
- DB 구조를 바꾸는 배포는 되돌릴 방법을 리뷰에 함께 적습니다.

## 배포 전 확인

- [ ] 설정 값이 환경마다 맞게 들어갔는가
- [ ] 되돌리는 방법을 알고 있는가
- [ ] 고객 응대팀이 바뀌는 내용을 알고 있는가
