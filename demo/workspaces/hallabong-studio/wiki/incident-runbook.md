# 장애 대응 런북

## 장애의 기준

- 주문이나 결제가 안 된다.
- 앱이 열리지 않는다.
- 농가가 주문을 확인할 수 없다.

위 셋 중 하나면 바로 장애입니다. 애매하면 장애로 봅니다.

## 역할

| 역할 | 하는 일                                      |
| ---- | -------------------------------------------- |
| 지휘 | 상황을 정리하고 결정한다. 직접 고치지 않는다 |
| 대응 | 원인을 찾고 고친다                           |
| 소통 | 고객 응대팀과 농가에 상황을 알린다           |

## 순서

1. 장애 채널을 열고 지휘를 정한다.
2. 최근 배포가 있었으면 먼저 되돌린다. 원인 분석은 그다음이다.
3. 15분마다 상황을 채널에 적는다.
4. 복구되면 30분 더 지켜본 뒤 종료를 알린다.

## 끝난 뒤

- 이틀 안에 회고를 한다.
- 회고는 사람이 아니라 구조를 본다. "누가 실수했나"가 아니라 "왜 실수가 그대로 나갔나"를 묻는다.
- 다시 생기지 않게 할 일을 티켓으로 만든다.
