# 귤밭 앱 리뉴얼 기획서

## 왜 하는가

- 첫 화면에서 제철 상품이 잘 보이지 않습니다. 첫 방문자의 절반 이상이 상품을 하나도 누르지 않고 나갑니다.
- 주문한 뒤에 "지금 어디쯤인지" 묻는 문의가 전체 문의의 3분의 1입니다.
- 화면마다 버튼과 글자 크기가 달라 새 기능을 붙일 때마다 디자인을 다시 합니다.

## 목표

1. 첫 방문자가 첫 화면에서 상품을 누르는 비율을 높인다.
2. 주문 상태 문의를 절반으로 줄인다.
3. 모든 화면을 디자인 시스템 컴포넌트로 바꾼다.

## 범위

| 화면      | 바꾸는 것                      | 담당 |
| --------- | ------------------------------ | ---- |
| 홈        | 제철 상품 카드, 농가 소개 위치 | 유진 |
| 상품 상세 | 이미지 뷰어                    | 민재 |
| 주문 내역 | 상태 단계 표시, 재주문         | 태양 |
| 농가 소개 | 신규 페이지                    | 유진 |

## 하지 않는 것

- 결제 흐름 변경 (결제·정산 개선 프로젝트에서 다룹니다)
- 태블릿 전용 화면

## 출시 기준

- 주요 화면이 글자 크기 최대 설정에서 깨지지 않는다.
- 구형 기기에서 검색 결과 스크롤이 끊기지 않는다.
- QA 시나리오 전체 통과.
